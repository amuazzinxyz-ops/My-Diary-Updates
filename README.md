# My Diary New — App Updates

This repository is only for distributing **My Diary New** app updates.

## What belongs here
- Signed My Diary New APK release files
- Version and update-check metadata
- Release notes for My Diary New

## What does not belong here
- App source project or private diary data
- Signing keystores, passwords, tokens, or other secrets
- Files for any other app

## Update safety
Only publish an APK built for the My Diary New Android application and signed with its existing trusted signing key. Before publishing an update, verify the application ID, version code, signing certificate, and APK SHA-256.

No update APK or release has been published by this README change.
